# 🌿 Garden Control Panel

Free Fire Craftland ke garden map ke liye ek companion website.

## Features
- **Planner** – 10/16/24 grid par flowers, trees, fountain, path, wall, bench, lamp, spawn, loot box lagao (click/drag; right-click = erase, Undo bhi hai).
- **Stats** – har item ka count aur "beauty score".
- **Map Info** – map name, Craftland map code, mode, players, description; code copy / share.
- **Tasks** – build checklist.
- **Save / Load** – browser mein auto-save, JSON export/import, layout PNG download.

## Kaise chalaye
Koi install nahi chahiye — `index.html` browser mein kholo.
Online chalane ke liye GitHub Pages on karo: Settings → Pages → Branch select karo → `/ (root)`.

> Note: Garena Craftland ka koi public API nahi hai, isliye ye website game ko direct control nahi karti.
> Yahan plan banao, phir Craftland editor mein wahi layout build karo.
